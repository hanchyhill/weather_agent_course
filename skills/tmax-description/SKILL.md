# 最高气温分布描述

## 输出格式

一段话，固定开头“最高气温具体分布为：”，以“其中××（地市+区县）录得全省最高气温××.×℃。”结尾。

## 步骤

1. 读图，记下各区域的气温范围和全省最高值（地市+区县，保留一位小数）。
2. 按温度分 2～4 类，每类区间跨度 2～4℃。
3. 温度相同的区域合并写，优先用大区名（粤北、粤东、粤西、珠三角），不再列出其下的市县。
4. 先写特例或范围较小的区域，最后用“其余大部分市县”概括。
5. 检查：不同区域的温度区间不交叉；地理范围不互相包含；全省都被覆盖。

## 用语

- 句式：“××市县介于X～Y℃之间”
- 写“气温”，不写“温度”
- 不写“天气炎热”“注意防暑”“总之”等

## 示例

最高气温具体分布为：粤东沿海市县、湛江、珠海介于32～34℃之间，其余大部分市县介于34～37℃之间，其中连州录得全省最高气温36.8℃。

## 分区参考

- 粤北：韶关、清远、河源、梅州北部
- 粤东：汕头、潮州、揭阳、汕尾
- 粤西：湛江、茂名、阳江、云浮
- 珠三角：广州、深圳、佛山、东莞、中山、珠海、江门、肇庆、惠州
