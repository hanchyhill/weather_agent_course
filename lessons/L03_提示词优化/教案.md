# L3 提示词优化：用分数说话

| 项目 | 内容 |
|---|---|
| 时长 | 3 小时 |
| 对应计划 | `plan/01-入门篇.md` L3 |
| 素材 | `mllm_test` tmax task5（阈值计数）：3 张最高气温实况图、站点真值、gpt-4o 真实错题 |
| 本讲文件 | `01_提示词AB实验.ipynb`（源文件 `.nb.py`，**需真实模型**）；`99_假模型剧本.ipynb`（没有 Key 时看流程用）、`tmax_task.py`（真值与评分）、`prompts/v1_基线.txt`、`prompts/v2_拆步骤.txt`、`练习_台风提示词找茬.md` |

## 教学目标

1. 会做控制变量的提示词 A/B 实验，用分数判断好坏。
2. 掌握常用的优化手段：拆步骤、先列证据再下结论、自检、明确边界条件。
3. 能区分“提示词能解决的问题”和“读图能力或数据本身的问题”。

## 讲解要点（40 分钟）

1. 为什么要结构化输出（JSON）：程序才能自动打分，后面的工具也才能接着用。
2. 看错题（notebook 第 1 节）：gpt-4o 数出 25 个县，真值 2 个，得 40 分。错误有三类：
   - “高于”理解成“高于或等于”；
   - 列表里写着 26.9 还说它高于 27，前后矛盾；
   - 读数本身是否准确，要对照原图才知道。
3. 优化手段与对应的错误：

   | 手段 | 管住什么错 |
   |---|---|
   | 明确边界：“严格大于，等于不算” | 高于/高于等于混淆 |
   | 拆步骤：先列读数 → 逐个判断 → 汇总 | 前后矛盾 |
   | 自检：Count 等于列表长度、列表中没有 ≤ 阈值的 | 计数对不上 |
   | 处理缺失：“读不清标 ?，不要猜” | 编造数值 |

4. 评分规则：计数 60%（完全对 100%，相差 20% 以内得 70%，50% 以内得 30%）+ 地理 40%（区县对得满分，只对地市得 60%）。
5. 不是所有失分都能靠提示词解决。mllm_test 的 README 提到黄埔、深圳宝安在图上没有数值，问到就必错，这是数据问题。

## 演示（20 分钟）

讲师运行 notebook 第 1～3 节。真实模型下 v1、v2 各跑一遍，投屏对比平均分。

## 实操（90 分钟，任选两项）

| 练习 | 内容 | 验收 |
|---|---|---|
| A 阈值计数 | 写 v3 提示词，对 3 张图跑分 | v3 平均分不低于 v2；报告写清改了什么 |
| B 控制变量 | 同一版提示词跑 3 次，看分数波动 | 说出“提升多少才算真的提升” |
| C 去掉地理表 | v2 去掉对照表再跑 | 比较地理分变化，解释原因 |
| D 台风提示词找茬 | 见 `练习_台风提示词找茬.md` | 找出至少 2 处问题并给出修改 |

成本控制：每次实验只跑 3 张图；真实模型下全班一次实验约 6 次调用/人。

## 复盘（30 分钟）

- 收集全班 v1、v2 平均分，画在白板上。
- 讨论：提升最大的是哪类错误？还剩下哪些失分？哪些是读图问题？
- 引出下一阶段：提示词决定模型怎么想、怎么写，但模型拿不到最新资料，要靠工具。

## 验收

- [ ] 提交 A/B 实验报告（notebook 第 4 节的表格）
- [ ] `uv run pytest lessons/L03_提示词优化` 通过（评分移植与 mllm_test 原评分一致，gpt-4o 错题得 40 分）

## 讲师备注

- `tmax_task.py` 的评分已用 mllm_test demo 的 gpt-4o 原回答验证：计数 0、地理 100、总分 40，与原评分文件一致。
- 3 张图的阈值与真值：01-01 阈值 27℃ 有 2 个县；01-06 阈值 26℃ 有 5 个；01-14 阈值 26℃ 有 16 个。最后一张县多，最能拉开差距。

## 常见问题

| 现象 | 处理 |
|---|---|
| 跑正式 notebook 报 `.env 中没有填写 MAIN_API_KEY` 或 `VLM_API_KEY` | 这一讲要用真实模型，没配 Key 先跑 `99_假模型剧本.ipynb` |
| 两次跑同一版提示词，分数差得多 | 正常。模型的输出每次都不一样，练习 B 就是练“提升多少才算真的提升” |

## FAKE 模式说明

正式讲义 `01_提示词AB实验.ipynb` 里**不写剧本**，全部用真实模型，避免学员把预设台词当成模型自己说的话。它靠源文件头部的 `<!-- course-meta: real-llm -->` 标记，`build_notebooks.py --execute` 只会转换、跳过执行。

没有 Key 时看 `99_假模型剧本.ipynb`：那一份用 `ask_image(..., fake_answer=...)` 写死剧本，并在第一格强制 `COURSE_FAKE_LLM=1`，打开就能跑，逐节对应正式 notebook。要跟学员强调：剧本里 v1 抄的是 gpt-4o 的历史错题、v2 抄的是真值，所以 v2 必然满分，那个平均分不能当实验结论；A/B 实验必须用真实模型才有意义。
