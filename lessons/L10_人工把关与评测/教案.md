## 教学目标

1. 能给“保存/发布”类工具加上人工确认，会用批准、修改、拒绝三种处理。
2. 了解长期记忆的用途（偏好、常用站点），知道它和 Skill 的区别。
3. 能制定评分表，用模型判官打分，并用人工分验证判官。

## 讲解要点（40 分钟）

1. 人工把关：`interrupt_on={"save_report": {...}}` + `checkpointer`。智能体在调用工具前暂停，把要执行的操作交给人。
2. 三种处理：批准、修改参数后执行、拒绝并说明原因。
3. “不能只看模型说了什么，要看工具实际做了什么”：`99_假模型剧本.ipynb` 里拒绝后模型仍说“已保存”（剧本写死的），正好用来说明这一点；正式讲义里则看 `outputs/` 下到底有没有生成文件。真实模型也可能表述不准，应查看工具实际返回；目录中旧文件的存在不能证明本次保存成功。
4. 长期记忆（概念讲解，不做练习）：deepagents 的 `memory=["./AGENTS.md"]` 会把文件内容写进系统提示词，适合放“本台写作偏好”“重点关注的站点”。和 Skill 的区别：记忆每次都加载，Skill 按需加载。
5. 评测三种方式：规则评分、人工评分、模型判官。判官要用人工分验证。
6. 台风报告评分表（6 项），对应台风专线中各步骤容易出错的地方。

## 演示（20 分钟）

- notebook 1：暂停 → 修改标题 → 保存，展示 `outputs/` 里的文件。
- notebook 2 第 2 节：判官给示例报告打分，看它能否查出“漏写灿鸿”和“误作生成概率”。

## 实操（90 分钟）

| 练习 | 内容 | 检查点 |
|---|---|---|
| 1（20 分钟） | 运行 `uv run python lessons/L10_人工把关与评测/hitl_cli.py`，分别试批准、修改、拒绝 | 根据工具返回核对：批准/修改执行，拒绝的调用未执行 |
| 2（30 分钟） | notebook 2 第 1 节：最高气温判官 vs 人工 | 算出平均绝对误差；把真值 CSV 加进判官提示词后再算一次 |
| 3（30 分钟） | 用 L8 的 3 份台风报告做 T10 | 人工分、判官分、三类扣分原因 |
| 4（10 分钟） | 为结课项目起草会商稿评分表 | 5～8 项，每项写清满分和扣分条件 |

## 复盘（30 分钟）

- 讨论：哪些项可以放心交给判官，哪些必须人看？
- 布置结课项目分组。

## FAKE 模式说明

两份正式讲义里**都不写剧本**，全部用真实模型：真实模型会自行决定回答，但可能表述不准；判官输出才可与人工评分比较。它们靠源文件头部的 `<!-- course-meta: real-llm -->` 标记，`build_notebooks.py --execute` 只会转换、跳过执行。

没有 Key 时看 `99_假模型剧本.ipynb`：前两节是 L10-1 的剧本（`llm.agent_model(call("save_report", ...), "会商稿已保存。")`），后两节是 L10-2 的剧本（`llm.ask(..., fake_answer=...)`，判官全给满分）。暂停、三种决定、文件读写、评分表计算都是真的，只有模型台词是假的。要跟学员强调：剧本册跑出来的平均绝对误差没有意义，只用来跑通流程。
