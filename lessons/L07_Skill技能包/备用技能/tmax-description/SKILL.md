# 最高气温分布描述（任务规约版）

依据广东最高气温图、统计时段和区域划分资料，输出中文业务描述。区域划分以提供的地理划分 CSV 为准。完整原文、示例和输入资料说明见 [原始任务规约](references/原始任务规约.md)；需要核对细节时读取；原文中的适用时段限制不适用于本技能，实际统计时段以输入资料为准。示例仅说明格式，不可照搬其数值。

## 处理步骤

1. 根据输入识别广东各市县气温范围、最高值及其地市和区县；明确统计时段。忽略明显不符合气象常识的异常数值，不要无依据编造数值或地点。资料不足时指出缺失或不确定之处，不假装完成。
2. 将全省气温划分为最多四段，每段跨度 2～4℃，使用整数边界；各段连续且内部不交叉，允许相邻区间共用边界，如 19～22℃、22～25℃、25～28℃。相邻或相似的区域可合并。原规约部分示例存在重叠，以此明确分段要求为准。
3. 同一区间有三个及以上市县时，根据区域划分汇总为适当区域；汇总后不重复列出所包含的市县，未汇总时列出相应市县。同一区间的地区可以合并描述。描述最高气温时不提及山区。覆盖全省，避免区域包含或重叠；不要将某些站点误当作整个区域。
4. 先描述偏冷、偏热或少数特殊区域，再描述“其余大部分市县”的主要区间。末尾写出全省最高气温的地市、区县和精确到一位小数的数值；多个区县最高值相同则全部列出。
5. 采用正式气象业务用语，避免口语和无关提示，温度范围使用“××市县介于 X～Y℃之间”。正式描述最多三句话，主干为“最高气温具体分布为：……，其余大部分市县介于……之间，其中……录得全省最高气温……℃。”

## 输出

先给出具体的温度分布分析，再将正式描述放在以下代码块中（这是原任务规约要求）：

```气象图像分析
最高气温具体分布为：{按资料填写的区域与区间}，其中{地市、区县}录得全省最高气温{数值}℃。
```

正式描述中的所有区域和数值必须来自当前资料。若提供的资料不足以完成其中某一步，明确说明局限，不要捏造。
