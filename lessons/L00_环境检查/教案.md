# L0 环境检查与 AI 编程助手入门

| 项目 | 内容 |
|---|---|
| 时长 | 3 小时（补装 30 分钟，讲解 40 分钟，实操 90 分钟，复盘 20 分钟） |
| 前置 | 学员已按 `plan/00a-课前准备与环境安装.md` 装好环境，并提交自检截图 |
| 对应计划 | `plan/01-入门篇.md` L0 |
| 本讲文件 | `check_env.py`（环境自检）、`01_时效表演示.py`、`需求写法范例.md` |

本课目录没有 notebook；以 `check_env.py`、`01_时效表演示.py` 和需求范例为教学材料，notebook 操作演示使用 L01 的正式 notebook。

## 教学目标

1. 每位学员的电脑都能跑通课程包，主模型和视觉模型都能调通。
2. 会用 Claude Code（或 Codex）完成三件事：读代码并解释、运行脚本、按需求修改代码。
3. 会用 VS Code 打开课程包、选 `.venv` 内核、逐格运行 notebook。
4. 知道一条好需求要写清：输入、输出、业务规则、验收方式。

## 课前准备（讲师）

- 收齐学员自检截图，标出没通过的人，课上优先帮他们补装。
- 准备好 `installers/windows/` 安装包和 `hosts.github.txt`，放到内网或 U 盘。
- 在讲台电脑上打开 Claude Code，提前跑一遍本讲的三个演示。

## 教学流程

### 1. 补装（30 分钟）

- 没通过自检的学员按《课前准备》补装；其余学员先阅读 `需求写法范例.md`。
- 常见问题对照《课前准备》第 11 节，最常见的三种：没有重开终端、`.env` 里多了空格、Key 余额不足。

### 2. 讲解（40 分钟）

1. AI 编程助手能做什么：读文件、改代码、跑命令。学员是“甲方”，AI 是“开发”。学员负责说清楚要什么、检查结果对不对。
2. 课程包结构（在 Claude Code 里让 AI 解释一遍，顺便演示“让 AI 读代码”）：

   | 目录 | 内容 |
   |---|---|
   | `common/` | 模型配置、课程时间、运行过程打印 |
   | `weather_tools/` | 气象工具（离线版），后面各讲的参考答案 |
   | `data/` | 离线数据：台风接口返回、路径图、最高气温图等 |
   | `lessons/` | 每讲一个目录：教案、示例代码、练习 |
   | `skills/` | L7 起使用的技能包 |
   | `tests/` | 自动验收用例 |

3. 一条好需求的四要素：输入、输出、业务规则、验收方式。对照 `需求写法范例.md` 讲解。
4. 安全习惯：Key 只放 `.env`，不粘贴进对话，不截图，不提交 git。

### 3. 实操（90 分钟）

**练习 1：环境自检（10 分钟）**

```powershell
uv run python lessons/L00_环境检查/check_env.py
```

全部显示“通过”才算完成。没有 Key 的学员先设 `COURSE_FAKE_LLM=1`，确认其他项都通过。

**练习 1b：在 VS Code 里运行 notebook（10 分钟）**

在 `course` 目录右键“通过 Code 打开”，双击 `lessons/L01_智能体是什么/01_第一个智能体.ipynb`，确认右上角内核是 `.venv`，运行前两格。讲师顺带演示：终端（Ctrl+`）、Claude Code 侧边栏、左侧资源管理器。

**练习 2：让 AI 解释代码（20 分钟）**

在 Claude Code 里输入：

> 运行 `lessons/L00_环境检查/01_时效表演示.py`，用中文解释输出的每一列是什么意思。

检查点：AI 能说清“起报时间是世界时 12 时，对应北京时 20 时；时效每 6 小时一档”。

**练习 3：让 AI 改代码（30 分钟）**

> 把 `01_时效表演示.py` 里的起报时间改成 2025 年 6 月 13 日 20 时（北京时），重新运行。

检查点：AI 应该把它换算成 `2025061312`（世界时）。如果 AI 直接写成 `2025061320`，脚本会报错（ECMWF 起报只有 00 和 12 UTC），借此引出 L5 的时区问题。

**练习 4：写一条需求（30 分钟）**

学员按四要素，给自己工作中的一个小需求写一段话（例如“把某个产品的图片地址规则整理成表”），两两互评：对方看了能不能直接动手做。

### 4. 复盘（20 分钟）

- 请 2～3 位学员展示练习 3 中 AI 的做法，比较谁的 AI 一次就换算对了，谁的没对，原因是什么（需求写得清不清楚）。
- 布置预习：阅读 `plan/01-入门篇.md` 的 L1。

## 验收

- [ ] `check_env.py` 全部通过（或 FAKE 模式下除模型外全部通过）
- [ ] 能说出时效表中“起报时间”“时效”“北京时”三列的含义
- [ ] 提交一条按四要素写的需求

## 常见问题

| 现象 | 处理 |
|---|---|
| `uv run` 很慢 | 检查 `uv.toml` 镜像配置（《课前准备》第 8 节） |
| Claude Code 改了不该改的文件 | 让学员养成习惯：先说“先告诉我你打算怎么改，不要动手”，确认后再让它改 |
| AI 说“已完成”但没运行 | 要求它“运行一遍并把输出贴出来” |
